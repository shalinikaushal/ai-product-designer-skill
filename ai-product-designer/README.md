# AI Product Designer Skill

An AI-powered product design skill that helps designers approach product challenges with structured thinking, user-centred design principles, and practical UX methodologies.

## Overview

The AI Product Designer Skill is designed to support product designers throughout the product design process — from understanding problems and exploring solutions to evaluating user experiences and improving design decisions.

It provides structured instructions that help compatible AI coding assistants deliver more consistent, thoughtful, and actionable product design support.

## Why This Project?

Product designers increasingly use AI tools in their daily workflows. However, generic AI responses often lack the context, structure, and critical thinking required for real-world product design.

This project aims to bridge that gap by providing a reusable skill that guides AI through a more structured product design approach.

## Key Capabilities

* **Product thinking:** Structure problems and understand user needs.
* **UX design:** Explore user journeys, flows, and interaction patterns.
* **Design research:** Support research planning and synthesis.
* **UX evaluation:** Identify usability issues and improvement opportunities.
* **AI product experiences:** Consider AI interactions, user trust, and responsible AI design.
* **Design decision-making:** Encourage clear reasoning behind design recommendations.

*Note: These capabilities should reflect the actual instructions implemented in SKILL.md.*

## Getting Started

### Installation in Cline

1. Clone or download this repository.
2. Open your project in VS Code.
3. Create the following directory if it does not already exist:

   `.cline/skills/ai-product-designer/`

4. Copy the skill's `SKILL.md` and its required supporting resources into that directory.
5. Enable Skills in Cline settings.
6. Start a new conversation and test the skill with a product design task.

### Usage

Give your AI assistant a product design problem.

Example:

"Help me redesign the onboarding experience for a personal loan application. Identify user pain points, propose improvements, and explain your design decisions."

The assistant should use the skill instructions when the task matches its scope.

## Example Prompts

**1. Product discovery**

Help me identify the user problems and opportunities for a new digital banking product.

**2. User journey**

Create an end-to-end user journey for an Indian personal loan application.

**3. UX audit**

Evaluate this user flow and identify usability issues, friction points, and missing states.

**4. AI product design**

Design a voice-based AI assistant experience for loan onboarding.

**5. Design critique**

Review this proposed solution from a senior product designer's perspective and suggest improvements.

## Compatibility

This skill is being developed and evaluated with Cline in VS Code.

## Limitations

* AI-generated recommendations require human review.
* Research findings should not be treated as real user evidence unless independently validated.
* Design recommendations should be checked against business, technical, accessibility, and regulatory constraints.
* Model capabilities and outputs may vary across AI providers.
