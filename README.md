# AI Product Designer

An agent skill that helps product designers move from user problems to evidence-based product decisions.

**Created by [Shalini Kaushal](https://github.com/shalinikaushal)**

## Overview

AI Product Designer is a reusable AI agent skill for UX research, product strategy, competitive intelligence, customer journey analysis, UX audits, and AI-powered experience design.

It helps designers produce structured, actionable deliverables instead of generic design suggestions.

## Capabilities

- **UX Research:** Research plans, interview guides, user insights and synthesis.
- **Competitive Analysis:** Competitor benchmarking, feature comparisons and opportunity mapping.
- **Journey Mapping:** User journeys, friction analysis and conversion opportunities.
- **Product Strategy:** Problem definition, PRDs, prioritisation and success metrics.
- **AI Experience Design:** Conversational AI, voice interfaces, agentic workflows and human handoffs.
- **UX Audits:** Usability, accessibility, interaction and information architecture reviews.

## Installation

Clone the repository:

```bash
git clone https://github.com/shalinikaushal/ai-product-designer-skill.git
```

Locate the `ai-product-designer` skill directory and copy it into the skills directory supported by your AI agent.

Follow your agent's instructions for loading custom Agent Skills.

## Example prompts

- Create a research plan for an Indian personal loan application.
- Compare the onboarding journeys of five fintech competitors.
- Map the customer journey for a voice-enabled loan application.
- Conduct a UX audit of a digital banking experience.
- Design a conversational AI flow for an RM-assisted loan application.

## Design principles

1. Evidence before assumptions.
2. User needs before features.
3. Business outcomes alongside usability.
4. Clear recommendations with measurable outcomes.
5. Responsible AI, transparency and human control.

## Compatibility

Designed for AI agents that support the open Agent Skills format. Compatibility and tool availability depend on the host agent.
